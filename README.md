# 套保有效性测试应用

本项目提供一个基于 Streamlit 的套保匹配与风险分析演示应用，包含基差风险、期限错配风险与有效性测试等可视化功能。

## 快速开始
1. 安装依赖（推荐使用虚拟环境）：
   ```bash
   pip install -r requirements.txt
   ```
2. 启动应用：
   ```bash
   streamlit run app.py
   ```
3. 打开命令行输出的本地链接（默认 http://localhost:8501/）即可查看界面。

## 功能概览
- **套保匹配引擎**：生成示例匹配数据并展示匹配成功信息。
- **基差风险分析**：展示错配分布、P/L 贡献、Time Lag vs P/L 关系与匹配质量指示器。
- **期限错配分析**：展示错配分布、交易量和 P/L 热力图、月差与 P/L 关系以及匹配质量仪表盘。
- **有效性测试**：按基准与货物维度计算价格变动、P/L、有效性比率和判定结果。

## 注意事项
- 当前示例数据为随机生成，用于演示流程；接入真实数据时需提供与 `app.py` 中匹配逻辑一致的字段。
- 如果在无图形界面的环境运行，可将 `streamlit` 的信息展示函数（如 `st.warning`）替换为日志或 `print`，便于调试。
